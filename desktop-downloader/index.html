YouTube Playlist Downloader

Download entire YouTube playlists easily with a clean, fast desktop interface.

Download App (.zip)

How to run the app:

  1. Extract the file: Right-click the downloaded desktop-downloader.zip file and select "Extract All...".
  2. Install Python: Make sure you have Python installed on your computer.
  3. Run the App: Open the extracted folder and double-click the run-desktop-version.bat file.
  4. First Run: The script will automatically install the required libraries (like `yt-dlp` and `flask`) and start the application in a new window!
