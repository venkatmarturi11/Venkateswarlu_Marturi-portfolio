Screen Recorder Extension

Record your screen, windows, or tabs with system audio and microphone for free.

Download Extension (.zip)

How to install in JioSphere / Chrome for free:

  1. Extract the file: Right-click the downloaded tab-recorder.zip file and select "Extract All..." to unzip it.
  2. Open Extensions page: Open your browser (JioSphere or Chrome), type chrome://extensions into the address bar, and hit Enter.
  3. Enable Developer Mode: Turn on the "Developer mode" toggle in the top-right corner of the page.
  4. Load the extension: Click the "Load unpacked" button in the top-left corner. Select the unzipped tab-recorder folder you extracted in step 1.
  5. Done! The Screen Recorder icon will appear in your browser toolbar. Pin it and click it to start recording.
Why do I have to install it this way?
Browser makers like Google disabled "one-click" extension installations from normal websites years ago for security reasons. Unless developers pay fees to publish to the official Web Store, extensions must be loaded manually via Developer Mode. This method is 100% free and safe!
